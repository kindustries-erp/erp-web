# Task: Setup PWA for Liouni ERP

**Status:** Plan Mode (Queue)
**Scope:** Enable Progressive Web App (PWA) capabilities for the Liouni ERP Web application to support offline access, installation on mobile/desktop, and improved performance.

## Phase 0: DB & Infrastructure Precheck

- [ ] **Icons Readiness:** Ensure app icons are available in `public/` (192x192 and 512x512).
- [ ] **HTTPS Verification:** Confirm production environment (Nginx Proxy Manager) has valid SSL (PWA requirement).
- [ ] **Result:** `DB_READY` (No database changes required for PWA setup).

## Phase 1: API / Backend Coordination

- [ ] **Static Assets serving:** Ensure NestJS (if serving frontend) or Nginx is configured to serve `.webmanifest` and service worker `.js` files with correct MIME types.
- [ ] **Caching Headers:** Review caching strategy for service worker files (should be `Cache-Control: no-cache`).

## Phase 2: Frontend Implementation (UI/FE)

- [ ] **Dependency Installation:**
  - `npm install -D vite-plugin-pwa`
- [ ] **Vite Configuration:**
  - Update `vite.config.ts` to include `VitePWA` plugin.
  - Define manifest: name, short_name, theme_color, icons, start_url.
- [ ] **Service Worker Registration:**
  - Configure `injectRegister: 'auto'` or manual registration in `App.tsx`.
  - Implement "Offline Ready" or "New Content Available" toast notifications (reuse `shared/components` if possible).
- [ ] **PWA Assets:**
  - Generate/place `manifest.webmanifest` or let Vite generate it.
  - Add `<link rel="manifest">` and meta tags in `index.html`.

## Phase 3: Quality Control (QC)

- [ ] **Lighthouse Audit:** Run Lighthouse PWA audit and achieve 100% score.
- [ ] **Offline Test:** Verify app loads basic shell and cached data when network is disconnected.
- [ ] **Installability Test:** Verify "Add to Home Screen" prompt appears on Android/iOS/Chrome.
- [ ] **Updates Test:** Verify new deployments trigger service worker updates correctly.

## Coordination Notes

- This task only affects `liouni-erp-web`.
- No Directus schema changes required.
- Deployment requires a full rebuild of the web container.
