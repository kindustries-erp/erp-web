# Lessons Learned

Thư mục này dùng để ghi lại các issue thực tế trong quá trình triển khai task và cách phòng tránh tái diễn.

## Quy tắc ghi nhận
- Nếu task gặp issue thực tế (bug, blocker, sai hướng), bắt buộc tạo/append entry theo template `_template.md`.
- Mỗi entry cần có: context, symptom, root cause, fix, preventive action.
- Ưu tiên mô tả ngắn gọn, actionable, và có thể tái sử dụng.

## Gợi ý tổ chức
- Có thể tạo file theo tháng: `lessons-YYYY-MM.md`
- Hoặc theo domain nếu lớn: `finance.md`, `auth.md`, `system.md`

## Mục tiêu
- Giảm lặp lỗi.
- Tăng tốc onboard cho agent/dev mới.
- Biến kinh nghiệm xử lý lỗi thành quy tắc có thể thực thi.
